# CAPE Wallpaper Deck

Agent 7 uses bundled Android demo wallpapers in `android/app/src/main/res/drawable-nodpi`:

- `wallpaper_focus.jpg`: dark minimal office/focus wallpaper for `WALLPAPER_FOCUS`.
- `wallpaper_relax.jpg`: calm warm home/recovery wallpaper for `WALLPAPER_RELAX`.
- `wallpaper_commute.jpg`: clean transit wallpaper for `WALLPAPER_COMMUTE`.
- `wallpaper_reset.jpg`: neutral restore/default wallpaper for `WALLPAPER_RESET`.

For a polished judge demo, you can replace these files with branded JPG or PNG exports from the design team, Figma exports, Unsplash/Pexels images with compatible licenses, or Samsung/One UI style assets you have permission to use. Keep the resource base names the same (`wallpaper_focus`, `wallpaper_relax`, `wallpaper_commute`, `wallpaper_reset`) and export at phone-wallpaper proportions, ideally 1440x3200 or higher.
