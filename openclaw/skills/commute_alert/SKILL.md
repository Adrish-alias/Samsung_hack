# Commute Alert Pack

Use this skill when:

- The user has an upcoming calendar event with a destination.
- Traffic ETA threatens punctual arrival.
- The user is not already at the destination.

Actions:

- Compute leave-by time.
- Send local notification and optional Telegram alert.
- Add a stress buffer when sleep debt or meeting load is high.

Safety:

- Never expose exact current coordinates in message text.
- Avoid repeated alerts after the user dismisses once.
